# 🎮 Calculadora de Partidas Rankeadas
Este é um projeto desenvolvido como parte do desafio de código da jornada de aprendizado na [DIO (Digital Innovation One)](https://dio.me) com o instrutor Felipão.
O objetivo é criar uma calculadora que recebe o número de vitórias e derrotas de um jogador, calcula o saldo de partidas rankeadas e determina o seu nível com base em regras de classificação.
---
## 🚀 Tecnologias Utilizadas
* **JavaScript**: Linguagem de programação utilizada para implementar toda a lógica do cálculo e estruturas de decisão.
* **Node.js**: Para executar o script localmente no terminal.
---
## 📊 Regras de Classificação
O nível do Herói é definido conforme a tabela abaixo:

Menor que 10 = Ferro

Entre 11 e 20 = Bronze

Entre 21 e 50 = Prata

Entre 51 e 80 = Ouro

Entre 81 e 90 = Diamante

Entre 91 e 100 = Lendário

Maior ou igual a 101 = Imortal
